# Code of Conduct

This project is a small, focused open-source tool. We expect all participants to be respectful and constructive in issues, pull requests, and discussions.

Unacceptable behavior includes harassment, personal attacks, spam, and other conduct that makes collaboration difficult for others.

Maintainers may remove or reject contributions that violate this code of conduct.

If you experience or witness unacceptable behavior, contact the maintainers listed in [README.md](README.md#-contact).
