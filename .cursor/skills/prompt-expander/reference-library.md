## REF: Other

Use this fallback when category is unclear.

**Universal section logic**
1. Hero with clear promise
2. What we offer
3. Featured content
4. Social proof
5. How it works
6. CTA block
7. Contact/footer

**Domain must-haves (examples)**
- Education: course cards, instructor cards, enrollment CTA
- Healthcare: services, doctors, booking, trust badges
- News: featured story, category tags, search
- Real estate: listing cards, filters, map
- Fitness: class schedule, trainer bios, membership tiers
- Finance: comparison table, calculators, security signals
- Non-profit: mission, impact metrics, donate/volunteer CTA

**Safe defaults**
- clean light background + one accent color
- readable sans-serif typography
- card-based content areas
- trustworthy tone unless user says otherwise
