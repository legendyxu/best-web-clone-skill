# Prompt Expander Reference Library

When users provide short or vague instructions (for example, "make it dark", "simplify the layout", or "emphasize mobile readability"), use this reference to expand them into specific, actionable guidance for the clone.

## Infer Website Type from URL

| URL pattern / domain | Type | Reference |
|---------------------|------|-----------|
| spotify, apple music, tidal, soundcloud, youtube music, youtube, bilibili, b23.tv, vimeo | Media | REF: Media |
| airbnb, booking, expedia, getyourguide, viator, travel, trip | Travel | REF: Travel |
| club, society, meetup, nonprofit | Community | REF: Community |
| shop, store, amazon, nike, zara, asos | Ecommerce | REF: Ecommerce |
| portfolio, dribbble, github pages | Portfolio | REF: Portfolio |
| restaurant, cafe, menu, nobu, food | Food | REF: Food |

---

## REF: Media / Entertainment

- Dark theme standard (Spotify model)
- Sidebar nav: Home, Search, Library
- Hover on cards: play button overlay
- Green/vibrant accent on dark
- Sections: Hero, Playlists, Artists, New Releases, Genre tiles, Charts

---

## REF: Travel / Tourism

- Light/warm theme (trust, adventure)
- Hero search bar above the fold
- CTAs: Book Now, Explore, Get a Quote
- Mobile-first
- Sections: Hero+Search, Destinations, Tours, Testimonials, Footer

---

## REF: Community / Organization

- Warm, approachable (greens, blues)
- Clear Join/Contact CTA
- Sections: Hero+Mission, About, Events, Members, Gallery, Join Us

---

## REF: Ecommerce / Product

- Clean, product-focused, white space
- Sticky header with cart
- Sections: Hero, Categories, Products, Reviews, Footer

---

## REF: Portfolio / Personal

- Strong personal branding
- Minimal nav, scroll-based
- Sections: Hero, About, Skills, Projects, Contact

---

## REF: Food / Restaurant

- Warm colors (oranges, creams, reds)
- Large food photography
- Sections: Hero, About, Menu, Reservations, Gallery, Location

---

## REF: Corporate / Business

- Professional (blues, grays, whites)
- Clear hierarchy
- Sections: Hero, Services, How It Works, Clients, Testimonials, Contact

---

## REF: Event / Landing Page

- Bold, energetic
- Countdown timer
- Sections: Hero, Overview, Speakers, Schedule, Tickets, FAQ

---

## REF: Other / Unknown

- Clean white/light gray + one accent
- Card grid for content
- Sections: Hero, What We Offer, Featured Content, Social Proof, Contact
